# Финальные доработки и полировка интерфейса

Реализация 6 запрошенных улучшений: отображение способов оплаты, замена круглых аватаров сторис на фирменные скругленные квадраты, унификация кнопок действия, навигация из сторис в профиль, кликабельные кольца историй и условное отображение кнопки оставления отзыва.

## User Review & Critical Decisions

> [!IMPORTANT]
> - **Оплата**: Отображение иконками в блоке информации профиля (наличные, карты, СБП, безналичный расчет для юрлиц).
> - **Форма сторис**: Скругленный квадрат (`borderRadius: 16-20px`) для превью историй в профилях и списках.
> - **Кнопки в поиске**: Автомагазины — «Позвонить», автосервисы, мойки и мастера — «Записаться».
> - **Отзывы**: Кнопка «+ Оставить отзыв» видна для автомоек, самомоек и автомагазинов, а для автосервисов и мастеров доступна только при наличии завершенного заказа/записи.

## 1. Overview & Core Concept

1. **Способы оплаты**: Вывод иконок (наличные, карта, СБП, счет) в карточке профиля на основе сохраненных настроек бизнеса/мастера.
2. **Скругленные аватары сторис**: Замена кругов (`borderRadius: 50%`) на скругленные квадраты с градиентной обводкой в профилях, унифицируя со стилем меню «Поиск».
3. **Логика кнопок Позвонить / Записаться**: Проверка типа бизнеса в поисковой выдаче и карточках.
4. **Переход из сторис в профиль**: При просмотре сторис в поиске клик по аватару или имени автора открывает полный профиль мастера/бизнеса.
5. **Кликабельные кольца историй**: В профиле мастера/бизнеса клик по аватару с градиентом новой истории открывает плеер сторис.
6. **Ограничение отзывов**: Кнопка добавления отзыва скрывается для автосервисов и мастеров, если у клиента нет подтвержденной истории обращений, при этом для автомоек, самомоек и магазинов она доступна всегда.
